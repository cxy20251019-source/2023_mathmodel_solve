# 数据层

- `raw/`：原始下载资料，尽量保留文件名及下载日期，不要覆盖。
- `interim/`：年度表的合并数据，先不做无依据的缺失值填补。
- `processed/`：用于具体模型的规范化表。
- `sources_template.csv`：Y1、Y2、X1～X6 的含义、单位、统计范围、来源链接等登记模板。

## 第一问规范表

| 字段 | 含义 |
|---|---|
| year | 年份（整数，唯一） |
| Y1、Y2 | 新能源汽车发展程度的两个候选指标，含义须来源核对 |
| X1～X6 | 候选影响因素，含义须来源核对 |

每一行的地域、年份、频率、统计口径必须一致。程序在没有明确决策时会拒绝缺失值，不会静默填充。不同指标的单位、正负向、是否需对数变换需要**分析前记录**。

GitHub 不保留空文件夹，因此用 `.gitkeep` 保留占位。后续正式上传数据时保留这些占位文件无妨。
