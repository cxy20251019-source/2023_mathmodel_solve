# 模型决策记录

## 已确定

1. 使用 Y1、Y2 作为新能源汽车发展水平的候选表征，但具体指标含义需通过来源表证实。
2. 使用 X1～X6 作为候选影响因素，先探索相关性，再用 VIF 和岭回归分析共线性及调整后关联。
3. 第一问按步骤实施，每次只推进经过验收的下一阶段。
4. 对重要因素开展敏感性/稳健性检验。

## 第一问 VIF 与岭回归

- 解释变量采用 X2、X3、X5、X6。以这四项和 Y1、Y2 均有观测值的 9 年（2014–2019、2021–2023）为样本，按年度原值拟合，保留各列原有含义和数值方向。
- 对每项 X，用其余 X 和截距拟合辅助回归，按 `VIF = 1 / (1 − R²)` 计算。数值精度下的完全共线用 `inf` 表示。 [NIST VIF 说明](https://www.itl.nist.gov/div898/software/dataplot/refman2/auxillar/vif.htm)
- 分别用这四项 X 拟合 Y1、Y2，标准化 X 后施加 L2 惩罚，截距自由估计。对每个目标分别用扩张窗口选择 `alpha`，首折用最早 5 个完整年份训练，每折验证下一个可用年份。标准化参数只由该折训练集计算。选参完成后用 9 年重新拟合，同时报告原单位系数和标准化系数。 [Hoerl 和 Kennard 的岭回归论文](https://doi.org/10.1080/00401706.1970.10488634)
- 目前只有 4 个用于选参的验证年份，`tuning_rmse` 用于记录选参过程。年度原值上的岭回归系数是小样本下的探索性关联，可能受共同时间趋势影响。

## 待确定

- Y1、Y2 与 X1～X6 的确切含义、单位、正负向及可比性。
- Y1、Y2 是分别分析还是构成综合得分；若合成，采用何种赋权与聚合方法。
- 年度时间趋势、共线性、样本容量对相关性/回归结果的影响。
- 合理的因素排序与敏感性分析方法。
