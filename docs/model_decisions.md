# 模型决策记录

## 已确定

1. 使用 Y1、Y2 作为新能源汽车发展水平的候选表征，但具体指标含义需通过来源表证实。
2. 使用 X1～X6 作为候选影响因素；先探索相关性，再讨论 CRITIC 与后续评价/解释模型。
3. 第一问按步骤实施，每次只推进经过验收的下一阶段。
4. 对重要因素开展敏感性/稳健性检验。

## 待确定

- 研究对象的国家/地区、年份范围、样本量与年度口径。
- Y1、Y2 与 X1～X6 的确切含义、单位、正负向及可比性。
- Y1、Y2 是分别分析还是构成综合得分；若合成，采用何种赋权与聚合方法。
- CRITIC 用在哪一组指标上（Y、X 或其他评价指标）；其权重不直接等于 X 对 Y 的影响程度。
- 年度时间趋势、共线性、样本容量对相关性/回归结果的影响。
- 合理的因素排序与敏感性分析方法。

**方法警示**：相关性不等于因果；CRITIC 的客观权重也不是因果效应。若最后使用解释性模型，应单独报告假设、系数意义、适用限制与稳健性。
